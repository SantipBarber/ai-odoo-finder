## Objetivo

Extraer contenido útil y limpio de los repositorios OCA en GitHub para mejorar la calidad de la información de cada módulo. Este contenido será la base para:
1. Mejores descripciones (ai_description)
2. Keywords más precisos
3. Embeddings más útiles

## Hallazgos de Exploración

### Estructura de Módulos OCA

Los módulos OCA tienen dos estructuras según la versión:

**Versiones nuevas (14.0+):** Usan `oca-gen-addon-readme`
```
module_name/
├── __manifest__.py
├── README.rst          ← GENERADO (lleno de badges/ruido)
├── readme/             ← FUENTE LIMPIA
│   ├── DESCRIPTION.rst ← Descripción funcional LIMPIA
│   ├── USAGE.rst       ← Cómo usar
│   ├── CONFIGURE.rst   ← Configuración
│   └── CONTRIBUTORS.rst
└── ...
```

**Versiones antiguas (≤13.0):** README manual
```
module_name/
├── __manifest__.py
├── README.rst          ← Contenido directo (hay que limpiar)
└── ...
```

|------|---------|-----------------|-------------------------|

## Estrategia de Extracción (con Plan B)

```
┌─────────────────────────────────────────────────────────────────┐
│                  ESTRATEGIA CON FALLBACK                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. Intentar: readme/DESCRIPTION.rst                            │
│     └─ Si existe → Usar directamente (ya está limpio)           │
│                                                                 │
│  2. Fallback: README.rst (o README.md)                          │
│     └─ Si existe → Limpiar badges, imágenes, formato RST        │
│                                                                 │
│  3. Último recurso: __manifest__.py description                 │
│     └─ Usar campo 'description' del manifest                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Pseudocódigo

```python
def get_clean_description(repo_name: str, version: str, module_name: str) -> str:
    """
    Obtiene descripción limpia con fallbacks.
    """

    # Plan A: readme/DESCRIPTION.rst (versiones nuevas)
    description_url = f"https://raw.githubusercontent.com/OCA/{repo_name}/{version}/{module_name}/readme/DESCRIPTION.rst"
    response = requests.get(description_url)

    if response.status_code == 200:
        return response.text  # Ya está limpio

    # Plan B: README.rst y limpiar
    readme_url = f"https://raw.githubusercontent.com/OCA/{repo_name}/{version}/{module_name}/README.rst"
    response = requests.get(readme_url)

    if response.status_code == 200:
        return clean_readme_rst(response.text)

    # Plan C: README.md
    readme_md_url = f"https://raw.githubusercontent.com/OCA/{repo_name}/{version}/{module_name}/README.md"
    response = requests.get(readme_md_url)

    if response.status_code == 200:
        return clean_readme_md(response.text)

    # Sin descripción disponible
    return None
```

## Funciones de Limpieza Necesarias

### clean_readme_rst()

```python
def clean_readme_rst(content: str) -> str:
    """
    Limpia README.rst de:
    - Badges de imagen (.. image::, |badge1|)
    - Comentarios RST (.. !!!!...)
    - Enlaces de imágenes (:target:, :alt:)
    - Líneas de separación (====, ----)
    - Múltiples líneas vacías
    """
    import re

    # Eliminar badges
    content = re.sub(r'\.\. \|badge\d+\|.*?$', '', content, flags=re.MULTILINE)
    content = re.sub(r'\|badge\d+\|', '', content)

    # Eliminar imágenes
    content = re.sub(r'\.\. image::.*?$', '', content, flags=re.MULTILINE)
    content = re.sub(r':target:.*?$', '', content, flags=re.MULTILINE)
    content = re.sub(r':alt:.*?$', '', content, flags=re.MULTILINE)

    # Eliminar comentarios generados
    content = re.sub(r'\.\.\s+!+.*?!+', '', content, flags=re.DOTALL)

    # Eliminar líneas de título RST
    content = re.sub(r'^[=\-~]+$', '', content, flags=re.MULTILINE)

    # Limpiar espacios
    content = re.sub(r'\n{3,}', '\n\n', content)
    content = re.sub(r'^\s+', '', content, flags=re.MULTILINE)

    return content.strip()
```

### clean_readme_md()

```python
def clean_readme_md(content: str) -> str:
    """
    Limpia README.md de:
    - Badges markdown ![](url)
    - Enlaces de imagen
    - Headers excesivos
    """
    import re

    # Eliminar badges
    content = re.sub(r'!\[.*?\]\(.*?\)', '', content)
    content = re.sub(r'\[!\[.*?\]\(.*?\)\]\(.*?\)', '', content)

    # Limpiar
    content = re.sub(r'\n{3,}', '\n\n', content)

    return content.strip()
```

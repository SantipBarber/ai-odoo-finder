# AI-OdooFinder

> **Find the perfect Odoo module with AI in seconds.**

An MCP (Model Context Protocol) server that enables LLMs to search Odoo modules in OCA repositories using hybrid search (semantic + full-text).

## The Problem

As an Odoo developer:

- You build features that already exist in OCA
- You spend hours searching for the right module on GitHub
- You install modules incompatible with your version
- You discover abandoned modules after integration

---

## The Solution

**AI-OdooFinder** provides:

- **Hybrid Search**: Combines semantic search (embeddings) with BM25 full-text
- **Version Filtering**: Only shows compatible modules (14.0 to 19.0)
- **AI Enrichment**: Descriptions, tags and keywords generated by Grok-4-fast
- **MCP Integration**: Use it from Claude, ChatGPT, Cursor, VS Code, Zed... via a public URL

---

## Architecture

```
┌──────────────────────────┐         ┌───────────────────────────────────────┐
│  Claude.ai / Desktop     │         │   Eticco infrastructure (Docker)      │
│  Claude Code · ChatGPT   │  HTTPS  │  ┌──────────────┐   ┌─────────────┐   │
│  Cursor · VS Code · Zed  │────────►│  │  MCP Server  │──►│   FastAPI   │   │
│  Windsurf · ...          │         │  │ (Streamable  │   │   backend   │   │
└──────────────────────────┘         │  │    HTTP)     │   └──────┬──────┘   │
   https://addon-finder.eticco.es    │  └──────────────┘          │          │
                                     │                     ┌──────▼──────┐   │
                                     │                     │ PostgreSQL  │   │
                                     │                     │ + pgvector  │   │
                                     │                     └─────────────┘   │
                                     └───────────────────────────────────────┘
```

**Usage modes:**
- **Remote MCP (recommended)**: Point any MCP client to `https://addon-finder.eticco.es` — nothing to install
- **Local MCP (STDIO)**: The [PyPI package](https://pypi.org/project/ai-odoofinder-mcp/) runs locally against your own backend (self-hosting)

**Components:**
- **MCP Server** (Streamable HTTP): public endpoint for MCP clients
- **FastAPI Backend**: hybrid search engine (internal)
- **PostgreSQL + pgvector**: 19,700+ modules with embeddings

> **Public instance** hosted by [Eticco](https://www.eticco.es). Search over OCA community modules is **open, no login required**. Eticco is also extending the service with its own internal modules; that part requires authentication and is for internal use only.

## Installation

**No installation needed.** AI-OdooFinder is available as a public remote MCP server:

```
https://addon-finder.eticco.es
```

| | |
|---|---|
| **Transport** | Streamable HTTP |
| **Authentication** | None for OCA community modules |
| **Tool** | `search_odoo_modules` |

Add that URL to your MCP client (see below). If your client only supports local STDIO servers, use the [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) bridge (requires Node.js):

```json
{
  "mcpServers": {
    "ai-odoofinder": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://addon-finder.eticco.es"]
    }
  }
}
```

### IDE/Client Configuration

<details>
<summary><b>Claude.ai Web / Claude Desktop</b></summary>

1. Go to **Settings** > **Connectors**
2. Click **"Add custom connector"**
3. Enter the MCP server URL:
   ```
   https://addon-finder.eticco.es
   ```
4. Save and start searching

> Custom connectors are shared between Claude.ai and Claude Desktop. On older Desktop versions without connectors, use the `mcp-remote` config above in `claude_desktop_config.json`.

</details>

<details>
<summary><b>Claude Code CLI</b></summary>

```bash
claude mcp add --transport http ai-odoofinder https://addon-finder.eticco.es
```

Usage:
```bash
claude
> I need an Odoo 17 module for subscriptions
```

</details>

<details>
<summary><b>ChatGPT (Developer Mode)</b></summary>

1. Go to **Settings** > **Apps & Connectors** > **Advanced** and enable **Developer Mode**
2. Create a new connector with URL `https://addon-finder.eticco.es`
3. Authentication: **None**

**Usage:**
```
Use ai-odoofinder to find Odoo 17 modules for inventory
```

</details>

<details>
<summary><b>VS Code (GitHub Copilot)</b></summary>

Create `.vscode/mcp.json` (project) or add it to your user `mcp.json`:

```json
{
  "servers": {
    "ai-odoofinder": {
      "type": "http",
      "url": "https://addon-finder.eticco.es"
    }
  }
}
```

> **For Business/Enterprise**: Admin must enable the "MCP servers in Copilot" policy.

</details>

<details>
<summary><b>Local STDIO package (self-hosted backend)</b></summary>

The [`ai-odoofinder-mcp`](https://pypi.org/project/ai-odoofinder-mcp/) PyPI package runs the MCP server locally and talks to the FastAPI backend REST API. The public instance does not expose that REST API, so this mode is meant for **your own deployment** (see [Deployment & Operations](docs/en/DEPLOYMENT_OPERATIONS.md)):

```json
{
  "mcpServers": {
    "ai-odoofinder": {
      "command": "uvx",
      "args": ["ai-odoofinder-mcp"],
      "env": {
        "AI_ODOOFINDER_API_URL": "http://localhost:8989"
      }
    }
  }
}
```

> Requires [uv](https://docs.astral.sh/uv/).

</details>

**Full configuration guide**: [MCP Client Configurations](docs/en/MCP_CLIENT_CONFIGURATIONS.md)

## Usage

Once connected, simply ask in natural language:

```
"I need a module for Odoo 17 that handles recurring payments"
```

Your assistant will call `search_odoo_modules` and show compatible OCA modules with their repository, summary and GitHub link.

Check the service status:

```bash
curl https://addon-finder.eticco.es/health
```

> The FastAPI REST API (`/search`, `/stats`) is only exposed in self-hosted deployments (`http://localhost:8989`).

## Development

### Requirements

- Python 3.14+
- [uv](https://docs.astral.sh/uv/) (dependency manager)
- Docker (for local PostgreSQL)

### Local Setup

```bash
# Clone
git clone https://github.com/SantipBarber/ai-odoo-finder.git
cd ai-odoo-finder

# Install dependencies
uv sync

# Configure variables
cp .env.example .env
# Edit .env with your credentials

# Start PostgreSQL
docker compose up -d db

# Run ETL (index modules)
uv run python scripts/etl_oca_modules.py

# Start API
uv run uvicorn backend.app.main:app --port 8989
```

Stack Tecnológico

⚡

FastMCP

Framework Python para servidores MCP. Decoradores simples, transporte dual STDIO/HTTP.

🔍

pgvector + BM25

Búsqueda híbrida: embeddings Qwen3 (2560 dims) + full-text con fusión RRF.

🚀

FastAPI

Backend async de alto rendimiento. Python 3.13+, documentación OpenAPI.

🤖

OpenRouter

Gateway unificado para LLMs. Qwen3 para embeddings, Grok-4 para enrichment.

🐳

Docker + Hetzner

Despliegue containerizado en VPS ARM64. ~5€/mes sin cold starts.

🔒

Tailscale Funnel

HTTPS automático sin configuración. Túnel seguro para acceso remoto.

DIALOGAR

Prompt Engineering y Context Engineering Avanzado

⚡ Principio Fundamental: "Calidad de Entrada → Calidad de Salida". El modelo no puede leer tu mente. La ambigüedad es el enemigo.

🎯 Objetivo

  • Evolucionar de prompts simples a flujo inteligente
  • Implementar Few-Shot con ejemplos concretos
  • Crear Chain of Thought de 4 pasos
  • Usar delimitadores efectivos para cada modelo

📐 Técnicas

  • Few-Shot Learning
  • Chain of Thought (CoT)
  • Delimitadores (═══, ⚠️, 🚨)
  • Ejemplos correctos vs incorrectos

📦 Entregable

  • Prompt de 100+ líneas estructurado
  • Flujo inteligente de clarificación
  • Sistema de confianza (HIGH/MEDIUM/LOW)

Flujo Inteligente de 4 Pasos

1. ¿Necesita clarificación?
→
2. Construir query óptimo
→
3. Interpretar por confianza
→
4. Instrucciones al LLM

Few-Shot Examples

server.py - QUERY_DESCRIPTION
LOCALIZATION QUERY EXAMPLES: • Spain + electronic invoice → "l10n_es_facturae facturae" • Spain + AEAT taxes → "l10n_es_aeat modelo" • Mexico + CFDI invoice → "l10n_mx_edi cfdi" • Argentina + AFIP invoice → "l10n_ar_afipws factura" User: "electronic invoicing for Spain" ✅ CORRECT: "l10n_es_facturae facturae FACE" ❌ INCORRECT: "electronic invoice e-invoice XML digital signature Spain..." ⚠️ For localizations: query of 2-4 words maximum ⚠️ The l10n_XX_ prefix is MORE IMPORTANT than synonyms
📝 Delimitadores por Modelo: Claude prefiere XML, GPT triple comillas, Gemini markdown. En nuestro prompt usamos caracteres visuales (═══, ⚠️) que funcionan en todos.

04

AUTOMATIZAR

De SKILL a MCP - El Gran Pivote

🔌 MCP = "USB-C para la IA": Un estándar abierto que conecta cualquier LLM con cualquier herramienta. Un solo protocolo universal.

🎯 Objetivo

  • Pivotar de Claude SKILL a MCP abierto
  • Implementar con FastMCP (decoradores)
  • Soportar STDIO + HTTP transporte
  • Compatibilidad con 9 clientes

🔄 Por qué Pivotamos

  • SKILL: Propietario Anthropic, beta cerrada
  • MCP: Estándar abierto, múltiples clientes
  • ChatGPT anunció soporte MCP (Sept 2025)
  • Control total de infraestructura

🔌 Componentes MCP

  • Tools: Funciones ejecutables ✓
  • Resources: Datos estáticos (no usado)
  • Prompts: Plantillas (no usado)

FastMCP - Decoradores Pythonicos
